# Science By HUGs Nexus

**Explore. Connect. Order.**

Customer-facing ordering and account PWA for the Science By HUGs ecosystem.

## Status

Initial PWA foundation for the Science By HUGs product family.

## Stack

- Vite
- TypeScript
- vite-plugin-pwa
- Static frontend deployment
- Supabase integration planned for business data/auth

## Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
